Price files

Save the year’s market prices as hledger P directives in prices/<year>/prices.journal, under the ledger root alongside import/. When import builds that year’s include file under import/, it adds the price file if present. You supply the prices hledger uses to value your holdings.

After running an import with available price files you’ll see a line has been added to import/2020-include.journal:

Each year’s include file then has the prices it needs, so a report on a single year values amounts correctly:

Keep prices out of directives.journal. hledger-flow passes that file to every statement conversion, so with incremental import each new price would rebuild every statement. Price files are only read by reports.

Commodity names

Section titled “Commodity names”

A price only applies to amounts that use the same commodity name. If your statements write US dollars as $, a price quoted in USD does not value them. Name the commodities in your price files the way your journals do, or add one price that links the two names:

hledger chains prices, so --value=then,$ can then use prices quoted in USD.

Fetch prices with pricehist

Section titled “Fetch prices with pricehist”

pricehist downloads currency, cryptocurrency and stock prices and prints them as P directives. Install it with pipx install pricehist or uv tool install pricehist, then list its sources with pricehist sources. Some sources, such as Alpha Vantage and CoinMarketCap, need a free API key.

To add only prices newer than those already saved, use -sx with the date of the last saved price instead of -s.

Fetch a year’s prices with hledger’s getprices

Section titled “Fetch a year’s prices with hledger’s getprices”

hledger’s getprices script picks a pricehist source for each commodity: currencies, cryptocurrencies or stocks. It takes your base currency, a commodity and a date range, so it can fetch one year at a time. Save it as prices/getprices and make it executable:

This writes the 2025 prices for every commodity used in 2025. It replaces that year’s price file only if it fetched something:

Replace USD with your base currency. hledger stats shows the one hledger guesses from your journal. getprices skips the base currency and expects ISO codes such as EUR and GBP. For the current year, use today’s date as the end date.

The loop only finds commodities that appear in the year’s transactions. A holding carried over from an earlier year, with no transaction that year, gets no prices. Add its opening balance to the year’s manual journal, or add the commodity to the list in the loop. Then run hledger-flow import, which adds the price file to the year’s include file if it is new.

hledger’s get command runs the same script, but always fetches from each commodity’s first transaction until today and saves one prices/<COMM>.prices file per commodity. hledger-flow does not include those files, because each one spans every year.
