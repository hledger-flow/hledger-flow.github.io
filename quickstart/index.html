Quick start

hledger-flow turns bank statements into journals and reports using hledger. Homebrew installs both. If you download a release instead, install hledger separately and put its executable on your PATH. The release binaries run without a Haskell toolchain.

Install with Homebrew

Section titled “Install with Homebrew”

On a supported Mac or Linux system, check that brew --version works in your terminal. If you’re new to Homebrew, install Homebrew and follow the installer’s instructions to add brew to your PATH.

If you don’t want Homebrew to install hledger, add --without-hledger to the install command. For later releases, run brew update and brew upgrade ferntrail/tap/hledger-flow.

Install on macOS

Section titled “Install on macOS”

Extract and run the download from your terminal, not Finder. hledger-flow is a command-line program, not an app bundle. If you open it from Finder, macOS refuses it with “Apple could not verify”, even though it is signed with a Developer ID and notarized.

On a Mac with Apple silicon, run this in the folder you downloaded to:

On an Intel Mac, use hledger-flow-macos-x64.tar.gz. If macOS asks whether to open a program downloaded from the Internet, click Open. After that it runs normally. Copy the extracted hledger-flow into a directory on your PATH.

Install on Windows

Section titled “Install on Windows”

Extract the ZIP using Extract All. Open PowerShell in the extracted folder and run .\hledger-flow.exe --version. Use the terminal for this CLI.

The Windows executable is unsigned. If SmartScreen shows Windows protected your PC, verify the ZIP first. If you trust the download, More info → Run anyway starts it when your device policy permits. File Explorer’s Properties → Details shows the version on builds that include version metadata.

Copy hledger-flow.exe to a folder on your user PATH, or add its folder under Edit environment variables for your account → Path and open a new terminal.

Build from source

Section titled “Build from source”

From a checkout of the repository, run stack install. Add the directory reported by stack path --local-bin to your PATH and install hledger. See the build instructions for prerequisites and tests.

Import your first statement

Section titled “Import your first statement”

Check that both commands are available in a new terminal:

To use a specific copy of hledger, pass its path before the command, for example hledger-flow --hledger-path /path/to/hledger import.

Start a ledger in an empty folder, then let hledger-flow status guide you. Each status ends with a Next: line saying exactly what to do:

  1. Put a statement where status says, for example import/me/mybank/checking/1-in/2026/statement.csv.
  2. Create the rules file status names. For a CSV with a header row, hledger-flow status --rules-template me/mybank/checking prints a starter to save as that file and edit.
  3. Run hledger-flow import. It creates all-years.journal.
  4. Point LEDGER_FILE at that journal with the line status prints, then run hledger-flow report. Reports go under reports/.

Running hledger-flow with no command does the same as status inside a ledger. Scripts and AI agents can use hledger-flow status --json; see status for scripts and agents. The step-by-step tutorial explains each part in depth.

On Windows, run chcp 65001 before querying the journal with standalone hledger. This sets the current terminal session to UTF-8 so currency symbols and accented letters display correctly. Then run hledger -f all-years.journal bal. In PowerShell, set LEDGER_FILE with $env:LEDGER_FILE = (Resolve-Path .\all-years.journal).Path.

Rules-based imports work on all three platforms. On native Windows you can put preprocess.ps1 and construct.ps1, or their .exe equivalents, in the account directory. See Windows import hooks for the arguments and commands to use from Command Prompt or PowerShell. For extensionless Unix shell scripts, use Linux, macOS, or WSL with Linux binaries.
